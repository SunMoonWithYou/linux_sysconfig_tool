# LinuxSysconfigTool

> 一个开箱即用的 Linux 系统配置交互式小工具，覆盖 SSH、网络、系统设置、维护四大模块，兼容 Debian/Ubuntu/CentOS/RHEL/Rocky/Alma/Fedora。

------

## 📖 简介

`LinuxSysconfigTool` 是一个纯 Bash 编写的 Linux 系统配置菜单工具，面向运维人员和 Linux 使用者，把日常高频的系统调整操作封装成**分类清晰、带交互、带备份、带审计**的一站式脚本。

无需记忆零散命令，也无需担心改坏配置——**每次修改前自动备份**，**每次写操作记入日志**，**破坏性操作二次确认**。

------

## ✨ 功能特性

### 🔐 SSH 管理

- 修改 SSH 端口（默认保留 22 端口，安全切换）
- 修改任意用户密码（`chpasswd` 方式，不泄露到进程列表）

### 🌐 网络管理

- **DNS**：修改 DNS 服务器，NetworkManager 环境自动持久化
- **端口管理**：放行 / 禁止端口，自动适配 ufw / firewalld / iptables
- **IP 协议**：IPv4 / IPv6 优先级切换、IPv6 开关、查看当前协议栈状态
- **Ping 开关**：启用 / 禁用 ICMP Echo 响应（立即 + 永久生效）
- **防火墙总开关**：一键启停 ufw / firewalld
- **hosts 管理**：查看 / 添加 / 删除 `/etc/hosts` 条目
- **网络诊断**：Ping、路由追踪、DNS 解析、端口连通性探测、本机监听端口
- **端口占用查看**：快速定位端口被谁占用

### ⚙️ 系统设置

- **时间与时区**：查看状态、手动设置时间、18 个常用时区快速切换、NTP 开关
- **磁盘 / 内存概览**：磁盘、inode、内存使用一览，`/` 下 Top 10 占用目录
- **软件源切换**：一键切换阿里云 / 清华 / 中科大 / 华为云镜像，支持恢复默认源
  - APT：兼容 Ubuntu 24.04+ / Debian 12+ 的 DEB822 格式与传统 `sources.list`
  - YUM/DNF：兼容 CentOS Stream / RHEL / Rocky / Alma / Fedora

### 🛠 维护工具

- **配置备份与回滚**：统一管理所有受管文件的备份，按编号一键回滚
- **操作审计日志**：所有写操作记录到 `/var/log/sysconfig-tool.log`，含时间、用户、动作

## 🛡 安全设计

| 机制                 | 说明                                                         |
| :------------------- | :----------------------------------------------------------- |
| **自动备份**         | 所有配置修改前生成 `文件名.bak_YYYYmmdd_HHMMSS` 备份         |
| **审计日志**         | 所有写操作记录到 `/var/log/sysconfig-tool.log`，含时间、操作用户、动作 |
| **二次确认**         | 关闭 IPv4、恢复默认源、回滚配置等破坏性操作需确认            |
| **SSH 端口安全策略** | 修改 SSH 端口时默认保留 22 端口，确认新端口可登录后再手动清理 |
| **密码安全**         | 使用 `chpasswd` 标准输入方式修改密码，不出现在命令历史或进程列表 |
| **DEB822 兼容**      | 自动识别新旧 APT 源格式，避免写错导致 `apt update` 失败      |
| **配置校验**         | SSH 重启前 `sshd -t` 校验，失败不重启                        |
